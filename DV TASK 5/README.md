# Healthcare Data Understanding, Cleaning & Exploratory Analysis

## Project Overview

This project focuses on understanding and cleaning healthcare data. The dataset contains information about patients, medical conditions, admission types, billing amounts, hospital stays, and other details.

The data is cleaned and analyzed to find useful patterns and basic information about patients and healthcare costs.

## Objectives

* Clean missing values in medical codes.
* Standardize date columns.
* Categorize patient admissions based on urgency.
* Calculate summary statistics for billing amounts.
* Analyze the number of days patients stay in the hospital.
* Study patient demographics for different medical conditions.

## Data Cleaning

### Missing Medical Codes

Missing values in medical code columns are identified and handled properly.

This helps keep the dataset clean and ready for analysis.

### Date Standardization

Date columns are converted into a standard date format.

This makes it easier to:

* Sort dates.
* Find admission periods.
* Calculate hospital stay duration.
* Perform time-based analysis.

## Admission Categorization

Admissions are grouped into three categories:

* **Emergency** – Patients who need immediate medical attention.
* **Urgent** – Patients who need medical attention quickly but may not require immediate treatment.
* **Elective** – Planned medical treatments or procedures.

This categorization helps understand the type of patient admissions.

## Summary Statistics

Summary statistics are calculated for:

### Patient Billing Amount

The analysis includes:

* Mean
* Median
* Minimum
* Maximum
* Standard deviation

### Hospital Stay

The number of hospital stay days is analyzed to understand how long patients remain in the hospital.

## Demographic Analysis

Patients are grouped based on **medical conditions** and demographic information.

This helps understand how different groups of patients are distributed across medical conditions.

## Key Insights

This analysis helps identify:

* The quality and completeness of the healthcare data.
* Common admission types.
* Typical patient billing amounts.
* Average hospital stay duration.
* Patient demographic patterns across medical conditions.

## Conclusion

This project performs basic **healthcare data understanding, cleaning, and exploratory analysis**.

The cleaned data and analysis can be used for further visualization, cost analysis, patient trend analysis, and healthcare decision-making.
