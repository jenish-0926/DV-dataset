# Student Performance Visualization & Analysis

## 📌 About the Project

This project analyzes student performance using Python and data visualization techniques. It focuses on understanding how **parental education, lunch type, and test preparation** are related to students' academic scores.

## 📊 Task 8 – Data Visualization & Analysis

In Task 8, I used the **processed and cleaned dataset from Task 7** to:

* Compare average scores using grouped bar charts.
* Analyze score variations using box plots.
* Create scatter plots for Math, Reading, and Writing scores.
* Generate a correlation heatmap.
* Identify educational patterns and provide policy recommendations.

## 🛠️ Tools Used

**Python | Pandas | Matplotlib | Seaborn | Google Colab**

## 🎯 Outcome

The project helps identify patterns in student performance and provides insights that can support **better academic planning, student support, and educational equity**.
